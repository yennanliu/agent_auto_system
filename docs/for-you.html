In one sentence

What is Agent Auto System?

It's a tool that hands boring, repetitive computer work over to AI assistants — the kind of tasks you'd normally do by clicking around a browser, copying things into a spreadsheet, or sending the same email over and over.

You pick a task from a menu, fill in a short form, and press Run. The AI does the work while you get on with something else. When it's done, you see a clear result — and a quality score so you know how much to trust it.

There's nothing to learn and no code to write. If you can fill in an online form, you can use it.

How it works

Three simple steps

1

Choose a task and fill a short form

Pick from the menu of ready-made tasks and answer a couple of questions — like "how many news stories?" or "which website?".

2

Press Run and watch it work

The task runs in the background. You can watch each step happen live, or come back later — it keeps going without you.

3

Get a checked, scored result

You get a clear answer, plus a quality score from a second AI that grades the work — so you know how much to trust it.

Why you can trust it

It double-checks itself

AI can make mistakes. So the system is built to catch them before you ever see the result.

✓

It checks its own work

Every result is inspected against a set of rules. If something looks wrong, the task is re-run automatically.

★

A second opinion scores it

A different AI grades each result from 0 to 100 — never the one that produced it — so the score stays honest.

↺

It recovers on its own

If one AI service is briefly unavailable, it quietly switches to another and keeps going. No lost work.

Getting started

How do I try it?

Agent Auto System is a free, open-source app. Someone technical on your team can set it up in a few minutes — the step-by-step Guide on the main page walks through it with screenshots.

Once it's running, it opens in your web browser like any website. You sign in, pick a task, and go. There's nothing to install on your own computer.

The only thing it needs is one AI key (from OpenAI, Anthropic, or Google) — a bit like a password that lets the app talk to the AI. Your team's setup person adds it once.

Good to know

Common questions

Do I need to know how to code?

No. Using the app is all point-and-click. Someone technical sets it up once; after that, anyone can run tasks from the browser.

Is it safe to give it my keys and data?

The app requires a login, and any saved keys are stored encrypted. It runs on your own team's server, so your data stays with you.

What if the AI gets something wrong?

The system checks each result and re-runs the task if it fails. A separate AI also scores the quality, so a low score is your signal to double-check.

How much does it cost?

The app itself is free and open-source. You only pay the AI provider for what you use, and every run shows its estimated cost so there are no surprises.
